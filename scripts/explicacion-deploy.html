Cómo se publican los cambios

Neo Mercado vs. Solve — para explicarlo en dos minutos.

Acá, en Neo Mercado

  1. Edito el código del proyecto.
  2. Lo pruebo en local antes de tocar lo real.
  3. Guardo el cambio en Git con git push.
  4. Vercel lo detecta solo y lo publica en 1-2 minutos.
Vos no hacés nada más

En Solve

  1. Se edita el código del proyecto.
  2. Alguien tiene que acordarse de deployar a mano.
  3. Si ese paso no se hace, el cambio queda listo pero no se ve online.
Paso manual, cada vez

Por qué la diferencia

Acá el repositorio está conectado directo a Vercel por Git: cada git push dispara sola la publicación. Es una conexión que se arma una sola vez y después queda funcionando así para siempre.

En Solve, si hay que deployar a mano todo el tiempo, es casi seguro que esa conexión automática todavía no está armada — el proyecto puede estar en otro tipo de hosting, o el repositorio no está enganchado a Vercel.

No es algo que tenga que repetirse siempre. Es una configuración puntual: conectar el repositorio del proyecto a Vercel (Import Project → elegir el repo de GitHub). Una vez hecho, Solve quedaría publicando solo, igual que acá.
